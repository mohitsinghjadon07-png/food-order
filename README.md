# Maison Rouge — Luxury Food Discovery

A responsive, static food discovery and ordering experience built with HTML, CSS and vanilla JavaScript. Designed for GitHub Pages.

## Features
- Editorial luxury visual direction using warm ivory, charcoal and crimson accents.
- Responsive restaurant and dish collection.
- Cuisine/category filters, search and sorting.
- Add-to-bag, quantity controls and subtotal calculation.
- Demo order confirmation with no payment integration.
- No backend, API key, build step or package installation required.

## Deploy with GitHub Pages
1. Download and extract the project ZIP.
2. Upload **index.html**, **styles.css**, **app.js** and **README.md** to the root of your `food-order` repository.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** in your repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then Save.
7. Wait for GitHub Pages to publish your site.

Your site will be available at:
`https://mohitsinghjadon07-png.github.io/food-order/`

## Important notes
- This is a front-end personal project/demo. The order confirmation is local to the browser; it does not send orders to restaurants.
- No online payment is collected or integrated.
- Food photography and Google Fonts are loaded from external services, so those visuals/fonts require an internet connection.
- Restaurant names, dishes, prices and ratings are illustrative demo content. Replace them with real data before presenting this as a live ordering service.
